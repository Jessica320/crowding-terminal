# 驗證協定（事先承諾，2026-10-26 凍結，早於任何回測）

| 設計項目 | 我們的選擇 |
|---|---|
| 訓練窗長度 | 擴張窗，從 2020-01-01 起，至少 365 天 |
| 每次往前滾的步長 | 1 季（日曆季） |
| 重訓頻率 | 每個 fold 重訓一次（每季） |
| 標籤期間 | 1 天（d 01:00 → d+1 01:00，含資金費） |
| 最長特徵回看期 | 30 天 |
| 驗證期間 | 2021-01-01 至 2024-12-31，16 個 fold（2021Q1 … 2024Q4） |
| Holdout | 2025-01-01 至 2025-12-31，封存；規格凍結後、經負責人同意才開一次 |
| Purging | 訓練集末端刪除 1 天（＝標籤期間）；加密貨幣 7×24，交易日＝日曆日 |
| Embargo | 不需要（訓練永遠在驗證之前） |
| 調參方式 | 巢狀：每個訓練窗最後 20% 當內部驗證（同樣 purge 1 天） |
| 主要指標 | 每日 Spearman IC，Newey–West 95% CI；CI 不含 0 才算有訊號 |
| 模型升階規則 | 上一階減下一階的每日 IC 差，HAC CI 下界 > 0 才採用較複雜的模型；否則用較簡單者 |
| 證偽條件 | ① 驗證期採用模型的 IC CI 包含 0；② 7 bp/邊下淨 Sharpe ≤ 0。任一成立 → 停止並誠實報告 |

實際切分日期由 `src/cv.py` 產生，存成 `outputs/folds.csv`，並記入 `run_log.csv`。

## 封存機制

- `src/config.research_only()`：研究程式讀資料後第一行呼叫，2025-01-01 以後的列一律刪除並 assert。
- `data/build_panel.py` 把 2025 的列另存在 `data/processed/sealed/`，研究腳本不讀這個資料夾。
- `08_holdout.py` 先寫 `outputs/HOLDOUT_OPENED.lock` 再讀封存資料；lock 存在時拒絕執行第二次。

## 帳本規則

每看一次結果、之後可能改變選擇，就在 `run_log.csv` 記一筆（`counts_as_trial=True`，`n_configs` 記該筆試了幾組設定）。修 bug 不算試驗。Deflated Sharpe 的試驗數 N＝計入列的 `n_configs` 總和。
